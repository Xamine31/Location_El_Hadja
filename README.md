# Location El hadja — PWA sans compilation, avec connexion par e-mail

Site statique GitHub Pages + Supabase. Même base de données sur iPhone, Android et PC, sans mot de passe. Les utilisateurs se connectent par lien e-mail à la première utilisation de chaque appareil, puis leur session est mémorisée.

**Commencez par lire [INSTALLATION-MAGIC-LINK.md](INSTALLATION-MAGIC-LINK.md).**

Fonctions : véhicules, immatriculations algériennes, maintenances, recettes, dépenses, filtres par véhicule et mois, montants en DA, PWA, configuration Web Push.
